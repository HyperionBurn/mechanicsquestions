## FORMULA SHEET (Provided in Examination)

**Equilibrium:** ∑Fₓ = 0, ∑Fᵧ = 0, ∑F_z = 0, ∑M = 0

**Truss Determinacy (Plane):** m + r = 2j (determinate), m + r < 2j (mechanism), m + r > 2j (indeterminate)

**Truss Determinacy (Space):** m + r = 3j (determinate), m + r < 3j (mechanism), m + r > 3j (indeterminate)

**Stress & Strain:** σ = F/A, ε = δ/L, E = σ/ε

**Thermal Expansion:** δ = α·L₀·ΔT

**Centroid:** x̄ = ∫x dA / A, ȳ = ∫y dA / A

**Second Moment of Area:** 
- Rectangle about centroid: I = bd³/12
- Circle about diameter: I = πd⁴/64
- Triangle about base: I = bh³/12
- Parallel Axis Theorem: Iᵤᵤ = Iₓₓ + Ae²

**Beam Bending:** M/I = σ/y = E/R, EI(d²v/dx²) = -M

**Standard Beam Deflections:**
- Cantilever with end load P: δ_max = PL³/(3EI)
- Simply supported with central load P: δ_max = PL³/(48EI)
- Simply supported with UDL w: δ_max = 5wL⁴/(384EI)

**Shear Stress:** τ = FAȳ / Ib, Torsion: τ = Tr/J

**Work-Energy:** Work = ΔKE + ΔPE + Work against friction

**Kinetic Energy:** KE = ½mv²

**Potential Energy:** PE_gravity = mgh, PE_spring = ½kx²

**Power:** P = F·v, P = Tω, Efficiency = Output Power / Input Power

**Impulse-Momentum:** F·Δt = m·Δv, Impulse = Change in Momentum

**Vector Operations:**
- Magnitude: |**F**| = √(Fₓ² + Fᵧ² + F_z²)
- Unit vector: **u** = **F**/|**F**|
- Dot product: **a**·**b** = |a||b|cosθ = aₓbₓ + aᵧbᵧ + a_zb_z

**Kinematics (Constant Acceleration):**
- v = u + at
- s = ut + ½at²
- v² = u² + 2as

**Circular Motion:**
- Tangential acceleration: a_t = dv/dt
- Normal acceleration: a_n = v²/r

**Principal Stresses:**
σ₁,₂ = (σₓ + σᵧ)/2 ± √[(σₓ - σᵧ)/2]² + τₓᵧ²

**Maximum Shear Stress:**
τ_max = √[(σₓ - σᵧ)/2]² + τₓᵧ²
