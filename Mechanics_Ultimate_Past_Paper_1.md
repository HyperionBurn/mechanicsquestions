## FORMULA SHEET (Provided in Examination)

**Equilibrium:** ∑Fₓ = 0, ∑Fᵧ = 0, ∑M = 0

**Truss Determinacy:** m + r = 2j (determinate), m + r < 2j (mechanism), m + r > 2j (indeterminate)

**Stress & Strain:** σ = F/A, ε = δ/L, E = σ/ε

**Thermal Expansion:** δ = α·L₀·ΔT

**Centroid:** ȳ = ∫y dA / A

**Second Moment of Area:** I = ∫y² dA, Rectangle: I = bd³/12, Parallel Axis: Iᵤᵤ = Iₓₓ + Ae²

**Beam Bending:** M/I = σ/y = E/R, EI(d²v/dx²) = -M

**Shear Stress:** τ = FAȳ / Ib

**Work-Energy:** Work = ΔKE + ΔPE + Work against friction

**Power:** P = F·v, Efficiency = Output Power / Input Power
